Steam 自动助手 · 本地助手（helper）使用说明
================================================

这个文件夹里的程序负责两件浏览器插件做不到的事：
  1. 读取你电脑上的 Steam 游戏库（含非 Steam 快捷方式、自定义加入的游戏）
  2. 在你下次启动 Steam 之后，按你勾选的顺序自动运行游戏

插件只负责界面和配置，真正的扫描与启动由这里的 helper.ps1 完成。

------------------------------------------------
一、三步用起来
------------------------------------------------
第 1 步：双击  start-helper.vbs
          助手会在后台无窗口启动，监听 http://127.0.0.1:17380/
          重复双击不会启动第二份（检测到端口占用会自己退出）。

第 2 步：浏览器里打开 Steam 商店页（https://store.steampowered.com/），
          点右下角悬浮球「助手」，切换到顶部「自动启动」页签。
          状态行显示「已连接」就说明助手通了。

第 3 步：在列表里勾选要自动运行的游戏，写好延迟秒数、间隔秒数，
          打开「Steam 启动后自动运行勾选的游戏」，点「保存」。

以后每次启动 Steam，助手会等「延迟秒数」后，按勾选顺序逐个启动这些游戏，
每两个之间间隔「间隔秒数」。同一次 Steam 会话只会触发一次。

------------------------------------------------
二、想让助手随 Windows 一起启动（可选）
------------------------------------------------
  右键 install-autostart.ps1 → 使用 PowerShell 运行
    会在当前用户「启动」文件夹放一个「Steam自动助手.lnk」，并立刻启动一次。
  想取消：右键 uninstall-autostart.ps1 → 使用 PowerShell 运行
    只删这一个快捷方式，不动任何其他文件。

------------------------------------------------
三、添加非 Steam 游戏 / 自定义路径的游戏
------------------------------------------------
Steam 里「添加的非 Steam 游戏」会被自动读到（读 userdata\<id>\config\shortcuts.vdf），不需要手工配置。

其他任何 exe 也可以加进来：用记事本编辑同目录的 custom-games.json，
格式如下（多个用英文逗号隔开）：

[
  { "name": "记事本", "exePath": "C:\\Windows\\System32\\notepad.exe" },
  { "name": "我的游戏", "exePath": "D:\\Games\\MyGame\\game.exe" }
]

保存后回插件点「重新扫描」即可看到，来源标签显示为「自定义」。
路径里有中文或空格都可以，反斜杠要写成两个（\\）。

------------------------------------------------
四、文件说明
------------------------------------------------
helper.ps1              主程序：HTTP 接口 + 库扫描 + 自动启动逻辑
start-helper.vbs        双击它，无窗口启动助手（UTF-16 LE 编码，这是 VBS 的要求）
install-autostart.ps1   注册开机自启
uninstall-autostart.ps1 取消开机自启
config.json             你的配置：总开关 / 延迟 / 间隔 / 已勾选的 id
custom-games.json       你手工加的自定义游戏
helper.log              运行日志，只保留最近 500 行

------------------------------------------------
五、常见问题
------------------------------------------------
Q: 插件里「自动启动」显示未连接？
A: 说明助手没在跑。双击 start-helper.vbs，然后点插件上的「重试」。
   如果双击没反应，看看 helper.log 最后几行有没有报错。

Q: 勾了游戏但 Steam 启动后没有自动运行？
A: 检查三件事：①「Steam 启动后自动运行勾选的游戏」开关是开的；
   ② 点过「保存」；③ 助手正在运行（插件状态行显示已连接）。
   另外，只有 Steam 从「没开」变成「开着」的那一刻才会触发，
   Steam 已经开着的时候再保存配置不会立刻触发。

Q: 想确认命令拼得对不对、又不想真的把游戏弹出来？
A: 接口支持空跑验证（不会启动任何进程）：
   Invoke-RestMethod -Uri http://127.0.0.1:17380/api/launch -Method POST -ContentType 'application/json' -Body '{"dryRun":true}'
   返回里会给出每个游戏将要执行的命令。

Q: 怎么停止助手？
A: 任务管理器结束 powershell.exe，或者命令行执行：
   Get-CimInstance Win32_Process -Filter "Name='powershell.exe'" | Where-Object { $_.CommandLine -like '*helper.ps1*' } | ForEach-Object { Stop-Process -Id $_.ProcessId }
